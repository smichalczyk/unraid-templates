# Unraid Community Applications templates

Templates published by [smichalczyk](https://github.com/smichalczyk) for Unraid's
Community Applications.

| App | What it does |
|---|---|
| [Framewrk](https://github.com/smichalczyk/framewrk) | Keeps Aura and Nixplay digital photo frames filled from your own PhotoPrism library |

Install through **Apps** in the Unraid web UI rather than from here — Community
Applications reads this repository and keeps the templates up to date for you.

Bug reports and questions belong on the app's own repository, linked above, not
here.
